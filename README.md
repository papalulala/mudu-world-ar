# 木都 AR｜GitHub Pages

網站：https://papalulala.github.io/mudu-world-ar/

使用者以手機或平板瀏覽器掃描實體木都插畫，讓有聲循環影片以懸浮薄板呈現在空間中。

## 自動部署

推送至 main 後，GitHub Actions 會檢查 JavaScript 與空間定位邏輯，然後將 dist/ 部署到 GitHub Pages。
在儲存庫 Settings → Pages 將 Source 設為 GitHub Actions。網站使用相對路徑，可在專案子路徑執行。

影片、圖片及 AR 引擎皆隨原始碼附上；不用額外的 API 金鑰。官方 XR Engine 受專屬授權約束，請保留其原檔與 LICENSE。這個專案沒有將第三方引擎重新授權為 MIT。

# 木都｜空間定位影片 AR

掃描實體木都插畫後，在圖片前方顯示一塊有厚度的影片面板。面板定位到本次 AR 體驗的世界座標；圖片離開鏡頭後仍保留在原位，由官方 SLAM 引擎持續追蹤手機的位移與旋轉。影片已換為「木都影片_音樂.mp4」的手機壓縮版本，約 61 秒，保留立體聲並循環播放。

## 使用方式

1. 用支援的手機 Safari 或 Chrome 開啟 HTTPS 網址。GitHub Pages 公開網站不需要登入 ChatGPT。
2. 點「開始掃描並開啟聲音」，允許相機與必要的動作／方向感測權限。
3. 在光線充足、周圍有紋理的環境中，緩慢移動手機建立追蹤，再對準木都圖片下半部中央的建築、噴水池與綠色隧道。
4. 保持圖片穩定約一秒，面板會自動定位並有聲循環播放。
5. 圖片離開鏡頭後仍可移動觀看面板。轉離面板時可能看不到它，但其位置保留；回頭可再次看到。
6. 「重新定位」會清除本次面板位置並要求重新掃圖。「從頭播放」「暫停影片」與聲音開關可控制影片。

若瀏覽器阻擋有聲自動播放，點「點一下，有聲播放」。手機系統音量也會影響是否能聽到聲音。

## 預覽與實機

- 「先看影片」可直接播放新版音樂影片。
- 「預覽懸浮面板」是非相機的 Three.js 示意，可調角度並隱藏圖片示意，檢查面板厚度和透視。示意不代表已完成手機實境追蹤驗證。
- 實體圖片可印出或在另一台螢幕顯示。同一支手機不能用後鏡頭掃自己正在顯示的畫面。
- 本次世界座標只在目前頁面／追蹤工作階段有效；關閉或重新整理網站需重新掃圖，不包含跨次體驗的永久空間定位。
- 環境追蹤真正變為 LIMITED 時會暫停影片並暫時隱藏面板，提示使用者恢復追蹤；單純圖片離開鏡頭不會暫停。
- 手機支援、光線、反光、純色表面與快速移動都會影響追蹤，可能需要重新定位。尚未用實體 iPhone、iPad 或 Android 裝置驗證效果。

## 技術與檔案

- 官方 @8thwall/engine-binary@1.0.0：圖片辨識與 SLAM 世界追蹤。dist/external/xr/ 保留官方原檔與 LICENSE。
- Three.js 0.170.0：影片貼圖、薄板幾何與透視顯示。
- dist/anchor-state.mjs：等待空間追蹤正常與圖片姿態穩定，鎖定世界位置。鎖定後不再依圖片更新座標。
- dist/video-panel.mjs：前面播放影片、背面為深綠色的薄板。
- dist/app.js：相機、權限、SLAM 事件、重定位與聲音播放控制。
- dist/preview.mjs：標明為示意的面板檢視器，不使用相機。
- dist/image-targets/mudu-city.json：由官方 @8thwall/image-target-cli@1.0.0 生成的局部圖片標記。
- dist/assets/world-config.json：局部標記至完整插畫的座標換算、穩定時間與面板浮起距離。
- dist/assets/mudu-music.mp4：1440 × 1080、H.264／AAC、CRF 23、192 kbps 音訊的新版影片。

原始影片與原始圖片均未覆寫。圖片辨識選用中央下半部的 480 × 640 細節區，程式將它換算回完整插畫的面板位置。面板與圖片平行，沿圖片正面法線浮起約完整圖片寬度的 4.5%；未指定真實公分尺寸，採引擎相對比例。

## 執行與檢查

需要 Node.js。執行 node server.mjs，開啟 http://127.0.0.1:4180/。手機實機使用 HTTPS 部署網址；一般區網 HTTP 通常無法使用相機。

執行 node tests/anchor.test.mjs，檢查：追蹤未正常時不定位、姿態穩定後定位、圖片消失後保留座標、鎖定後圖片移動不拖走面板、觀看透視改變而世界矩陣不變、重定位與無效資料拒絕。

瀏覽器已初始化官方引擎並確認世界追蹤／圖片辨識／Three.js 整合模組可用；面板示意與新版影片的音軌、循環、播放與暫停已檢查。手機真實 SLAM 效果仍需現場驗證。
